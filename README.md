# ÁUREA - Landing Page de Evento Nocturno 🌙

**Áurea** es una landing page de alto impacto diseñada y desarrollada para una marca de eventos nocturnos. El objetivo principal del proyecto fue centralizar la información de las próximas fechas, capturar la esencia visual de la marca y facilitar la conversión mediante la venta de entradas online.

---

## 🚀 El Proyecto

Este proyecto fue desarrollado **de punta a punta (End-to-End)**, partiendo de una fase de investigación de la identidad visual del cliente en redes sociales para trasladar esa atmósfera "editorial y aspiracional" al entorno digital.

### Características Principales:
* **Diseño UI/UX Personalizado:** Prototipado de alta fidelidad realizado en Figma, enfocado en una jerarquía visual clara y una estética minimalista.
* **Componentes Dinámicos:** Implementación de un contador regresivo (countdown) para el próximo evento, integración de mapas y gestión dinámica de links de venta.
* **Experiencia Inmersiva:** Uso de animaciones fluidas y transiciones suaves para mantener el engagement del usuario.

---

## 🛠️ Tecnologías y Herramientas

### Frontend
* **HTML5 & CSS3:** Estructura semántica y diseño responsive con enfoque en Mobile-First.
* **JavaScript (ES6+):** Lógica para elementos dinámicos y manipulación del DOM.
* **GSAP (GreenSock Animation Platform):** Biblioteca principal para animaciones de alto rendimiento.
* **Swiper.js & SimpleLightbox:** Para una galería de fotos interactiva y profesional.

### Backend & Deployment
* **Node.js:** Entorno de ejecución para la gestión de dependencias y lógica del servidor.
* **Cloudflare:** Gestión de DNS y optimización de seguridad para el dominio.
* **Hostinger:** Infraestructura de hosting para el despliegue del sitio.
